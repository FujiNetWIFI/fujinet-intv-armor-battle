# Armor Battle — FujiNet netplay port

Work in progress: fourth Intellivision netplay port (after Baseball, Auto
Racing, NFL Football). Two consoles run the original 1979 Armor Battle ROM,
lightly patched, in delay lockstep over FujiNet.

Status: M0 (scaffold). See `PORTING.md` §8 for the milestone sequence and
`spikes/NOTES.md` for the plan-time recon. This file is rewritten with the
full architecture and build/test documentation at release.
